# 크롬 Claude 에 붙여 넣을 조작 지시문

녹화는 사람이 화면 녹화 프로그램으로 하고, 크롬 Claude(Claude in Chrome)는 아래 순서대로 상황판을 조작한다.
시작 전: m14 에서 `flood_headless/web/run_server.sh prep`, 크롬 탭에서 `http://localhost:8765` 열어 두기(VS Code 포트 포워딩).

---

아래를 그대로 크롬 Claude 에 붙여 넣는다.

```
지금 열려 있는 http://localhost:8765 탭(도림천 침수 상황판)을 시연 녹화용으로 조작해 줘.
규칙
- 이 탭만 쓰고, 다른 사이트로 이동하거나 새 탭을 열지 마.
- 키 입력 전에는 페이지 빈 곳(제목 "상황판" 근처)을 한 번 클릭해서 입력칸에 커서가 없게 해.
- "에이전트 판단 중" 표시(시계 상자 오른쪽 주황 표시)가 보이면 사라질 때까지 기다려. 보통 1~2분 걸려. 5초마다 확인하고 그 사이에는 아무것도 누르지 마.
- 오른쪽 "에이전트 일지"의 새 카드에 제안 카드(색 배지와 승인 버튼)가 생기면 그 실행이 끝난 거야.
- 각 단계 사이에 3초씩 쉬어서 화면이 보이게 해.

순서
1. 03:55 화면 훑기: 상황판에서 3초 머문 뒤, 왼쪽 메뉴 "위험 지도" 클릭 → 3초, "레이더 영상" 클릭 → [재생] 버튼 클릭 → 5초 → 왼쪽 "상황판" 클릭.
2. 키보드 Space 를 한 번 눌러 시계를 흘려. 04:00 에 오른쪽 일지에 자동 실행 카드가 생기고 활동 줄이 쌓여. 제안 카드가 뜰 때까지 기다려.
3. 제안 카드가 뜨고 시계가 다시 흐르면 Space 를 눌러 멈춰.
4. 키보드 2 를 눌러(13:05 로 이동), Space 로 흐르게 해. 13:10 에 자동 실행이 시작되면 기다리는 동안:
   - 강우 그래프 위 [레이더 유역평균] 버튼 클릭 → 3초 → [AWS 강우 평균] → 3초 → [전체]
   - 아래 "수위계 현황" 목록의 첫 번째 줄 클릭(아래 수위계 상세가 바뀜)
   제안 카드가 뜰 때까지 기다린 뒤 Space 로 멈춰. 그 다음 "위험 지도" 클릭 → 5초 → "레이더 영상" 클릭 → [재생] → 6초 → "상황판".
5. 키보드 3 을 눌러(20:35), Space. 20:40 자동 실행이 끝나 제안 카드가 뜨면 카드의 [승인] 버튼을 클릭하고, Space 로 멈춰. 그 다음 "위험 지도" 클릭 → 6초 → "상황판".
6. 오른쪽 위 "예보관 질문" 입력칸을 클릭하고 "신대방 쪽 지금 어때? 앞으로는?" 을 입력한 뒤 [질문] 클릭. 새 카드의 제안 카드가 뜰 때까지 기다려.
7. 페이지 빈 곳 클릭 → 키보드 4 (21:55) → Space. 22:00 자동 실행이 끝나 제안 카드가 뜨면 Space 로 멈춰.
8. 왼쪽 "검증" 클릭 → 위에서 아래로 천천히 스크롤(3초 간격 3번) → 끝.
각 단계를 마칠 때마다 무엇을 했는지 한 줄로 알려줘.
```

---

## 상황판 키 정리
| 키 | 동작 |
|---|---|
| Space | 시계 흐름 / 멈춤 |
| N | 다음 감시 사건 3분 전으로 이동하고 흐름 |
| 1 / 2 / 3 / 4 / 5 | 03:55 / 13:05 / 20:35 / 21:55 / 다음날 00:25 로 이동 (멈춘 상태, 자동 실행 켬) |
| O | 숨긴 조작 막대 보이기 / 숨기기 |

## 주의
- 크롬 Claude 는 브라우저만 조작하고 영상은 찍지 않는다. 녹화는 OBS 같은 화면 녹화로 따로 한다. 크롬 Claude 옆 패널이 녹화에 안 나오게 녹화 영역을 탭 화면으로 잡는다.
- 에이전트 실행은 매번 실제 claude 실행이라 1회 약 0.3 달러, 전체 약 5회.
- 크롬 Claude 가 기다리지 않고 키를 연달아 누르면 장면이 꼬일 수 있다. 꼬이면 `run_server.sh prep` 으로 처음부터.
