# 도림천 예보관 콘솔 시안 (2022-08-08 재생)

예보관용 대시보드 시안. 정적 HTML 한 장(`dorim_console.html`)이고, 숫자는 모두 실제 자료다.

- 탭: 상황판 · 위험 지도 · 레이더 영상 · 검증. 오른쪽에 경보 기록과 브리핑 고정.
- 시점: 08:00(03시 예보) · 14:00(09시) · 20:00(15시) · 23:00(21시). 한 화면 = 한 시점 = 한 예보.
- 위험 표시: 위치는 sjbae 모델 위험 순위, 범위는 강우 단계(3시간 최대 강우)별 상위 %, 배수분구는 필지의 5 % 이상이 표시 대상이면 위험 표시 분구.
- 브리핑 문장은 아직 자료로 조립한 예시다 (claude 헤드리스 연결 전).

## 구성
| 경로 | 내용 |
|---|---|
| `console_tpl.html` | 화면 템플릿 (자료 자리표시자 포함) |
| `build.py` | `data/` 를 넣어 `dorim_console.html` 생성 |
| `data/dash_0808.json` | HSP 10분 유역평균, 서울시 AWS 10분 6곳, LDAPS 발표별 유역평균, 하수관 수위계 28곳 10분 |
| `data/tabs_0808.json` | 시점별 블렌드 위험(분구, 순위 판정), 하루 종료 후 결과, 레이더 프레임 144장, 침수흔적 집계 |
| `data/geo.json` | 자치구·배수분구·하천·유역 경계 (단순화) |
| `data/terrain.jpg` | DEM 5 m 음영기복 + 고도 색 |
| `tools/` | 자료 추출 스크립트 (extract_0808.py, extract_tabs.py) |
| `eval/` | sjbae 모델 독립 사건 검증(eval_sjbae), 강우 단계 보정(calib_stage)과 결과 csv |

위험도는 `../bin/flood_tool blend` 결과(`../outputs/20220808/blend/`)에서 가져왔다.
`tabs_0808.json` 의 blend·ranked·traces 항목은 작업 중 짧은 스크립트로 덧붙였고, 그 단계는 아직 tools/ 에 정리되지 않았다.
